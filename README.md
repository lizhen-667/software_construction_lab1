## 五、如何修改与重新生成

### 5.1 改文档正文（推荐方式）

文档正文全部由 `build/report_spec_*.py` 控制，**改脚本比改 Word 更不容易破坏格式**。

1. 按模块找到对应文件：
   - 系统角色 / 总体流程 / 模块一 → `build/report_spec_a.py`
   - 模块二 / 模块三 → `build/report_spec_b.py`
   - 模块四 / 模块五 / 附录 → `build/report_spec_c.py`

2. 定位到要改的段落。常用的块函数：

   | 函数 | 生成内容 |
   |---|---|
   | `h2("3. 模块一：用户与权限管理")` | 一级标题 |
   | `h3("3.1 用户注册与审核　[申请者、系统、管理员]")` | 用例标题（方括号内为主要参与者） |
   | `p("……")` | 正文段落（自动首行缩进 2 字符） |
   | `st("1. 申请者请求注册……")` | 事件流步骤（缩进显示） |
   | `tb("表X-Y　表名", [表头], [[行1], [行2]])` | 表格（表题在表上方） |
   | `draw("图X-Y　图名", "布局说明", ["要素1", "要素2"], "绘制提示")` | 图 / 绘制说明块 |

3. 重新生成：

   ```bash
   python build/gen_report.py      # 生成 .md 和 .docx
   ```

> ⚠️ **生成前请关闭 Word** 里打开的 `系统原型.docx`，否则会提示文件被占用。

### 5.2 改界面原型图

```bash
# 1. 编辑页面定义（改文字、字段、示例数据）
#    build/pages_a.py ~ pages_e.py
#    改整体配色 / 样式 → build/wire_kit.py

# 2. 重新生成 36 个 HTML
python build/gen_wireframes.py

# 3. 用浏览器打开 build/wireframes/MB-XXX-N.html 查看效果
#    满意后再截图替换 build/shots/ 里的 PNG
```

### 5.3 改泳道图

```bash
# 1. 编辑 build/gen_swimlanes.py 里的节点定义
#    每张图的 lanes（泳道）、nodes（节点）、edges（连线）

# 2. 重新生成 SVG
python build/gen_swimlanes.py

# 3. 浏览器打开 build/diagrams/preview.html 查看，再导出 PNG
```

## 七、环境依赖

只用 Python 3，脚本本身无第三方依赖（界面图与泳道图由浏览器渲染，脚本只负责生成 SVG / HTML）。

```bash

```

生成 Word 文档需要 `python-docx`：

```bash
pip install python-docx
```
